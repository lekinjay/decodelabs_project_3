# 🗄️ Project 3: Relational Database Analysis (SQL)

## 🎯 Objective
The primary objective of this project was to transition the cleaned transactional dataset into a PostgreSQL relational database environment. By structuring and executing complex database queries, this analysis extracts advanced business intelligence metrics, tracks granular performance data, and builds structured views for relational data management.

---

## 🛠️ Database Queries & Performance Frameworks
The backend SQL architecture was developed to answer key commercial inquiries through targeted relational scripts:

* *Transactional Aggregations:* Engineered robust aggregation scripts utilizing functions like SUM(), COUNT(), and AVG() to calculate high-level performance baselines across corporate sales.
* *Product & Revenue Optimization:* Structured data scripts to isolate product performance trends, identifying peak commercial drivers by total revenue and total volume metrics to guide inventory decisions.
* *Fulfillment Metrics & Status Filters:* Implemented advanced conditional filtering clauses to dissect operational fulfillment channels, specifically targeting transaction frequencies across shipped, cancelled, and returned order states.
